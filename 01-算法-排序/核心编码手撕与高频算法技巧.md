### 1.1 词频统计与按元素频率排序

#### 题目描述
1. **基础版**：给定字符串列表，忽略大小写统计每个单词出现的次数，返回 `Map<String, Integer>`。
2. **进阶版**：给定一个整数数组 `arr = {4, 5, 6, 4, 5, 4, 7}`，按元素出现频率**降序**排列；若频率相同，则按元素值**升序**排列，返回展开后的列表 `[4, 4, 4, 5, 5, 6, 7]`。

#### 参考答案

```java
import java.util.*;
import java.util.stream.Collectors;

public class FrequencySortDemo {

    // 1. 单词频率统计（忽略大小写）
    public static Map<String, Integer> countWords(List<String> words) {
        Map<String, Integer> countMap = new HashMap<>();
        for (String word : words) {
            if (word == null) continue;
            String key = word.toLowerCase();
            // 写法 A：getOrDefault
            // countMap.put(key, countMap.getOrDefault(key, 0) + 1);
            // 写法 B（更优雅）：使用 Map.merge
            countMap.merge(key, 1, Integer::sum);
        }
        return countMap;
    }

    // 2. 按元素频率降序、同频按值升序排列
    public static List<Integer> sortByFrequency(int[] arr) {
        Map<Integer, Long> freqMap = Arrays.stream(arr)
                .boxed()
                .collect(Collectors.groupingBy(e -> e, Collectors.counting()));

        return freqMap.entrySet().stream()
                .sorted((e1, e2) -> {
                    int freqCompare = Long.compare(e2.getValue(), e1.getValue()); // 频率降序
                    return freqCompare != 0 ? freqCompare : Integer.compare(e1.getKey(), e2.getKey()); // 值升序（严禁使用减法防溢出）
                })
                .flatMap(entry -> Collections.nCopies(entry.getValue().intValue(), entry.getKey()).stream())
                .collect(Collectors.toList());
    }

    public static void main(String[] args) {
        List<String> words = Arrays.asList("apple", "Banana", "apple", "orange", "banana", "apple");
        System.out.println("词频统计: " + countWords(words)); // {orange=1, banana=2, apple=3}

        int[] arr = {4, 5, 6, 4, 5, 4, 7};
        System.out.println("频率排序: " + sortByFrequency(arr)); // [4, 4, 4, 5, 5, 6, 7]
    }
}
```

### 1.2 自定义对象去重与多字段复合排序

#### 题目描述
给定 `List<Person>`，其中 `Person` 包含 `name`（String）和 `age`（int）。请实现方法返回一个**按年龄升序、同龄按姓名字典序升序**的**去重**列表（姓名和年龄均相同视为重复）。

#### 参考答案

```java
import java.util.*;
import java.util.stream.Collectors;

class Person {
    private final String name;
    private final int age;

    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }

    public String getName() { return name; }
    public int getAge() { return age; }

    // 核心契约：重写 equals 必须同步重写 hashCode
    @Override
    public boolean equals(Object o) {
        if (this == o) return true;
        if (!(o instanceof Person p)) return false;
        return age == p.age && Objects.equals(name, p.name);
    }

    @Override
    public int hashCode() {
        return Objects.hash(name, age);
    }

    @Override
    public String toString() {
        return "Person{name='" + name + "', age=" + age + "}";
    }
}

public class UniqueSortedPeople {
    public static List<Person> getUniqueSortedPeople(List<Person> people) {
        return people.stream()
                .distinct() // 依赖 equals() 和 hashCode()
                .sorted(Comparator.comparingInt(Person::getAge)
                        .thenComparing(Person::getName))
                .collect(Collectors.toList());
    }

    public static void main(String[] args) {
        List<Person> people = Arrays.asList(
                new Person("Alice", 30),
                new Person("Bob", 25),
                new Person("Alice", 30), // 重复元素
                new Person("Charlie", 25)
        );
        System.out.println(getUniqueSortedPeople(people));
        // 输出: [Person{name='Bob', age=25}, Person{name='Charlie', age=25}, Person{name='Alice', age=30}]
    }
}
```

> **面试关键点**：
> 1. `Stream.distinct()` 与 `HashSet` 去重均依赖 `hashCode()` 和 `equals()`。
> 2. 若不重写 `equals/hashCode` 而想按特定属性去重排序，可使用 `TreeSet` 传入自定义 `Comparator`：
>    `new ArrayList<>(new TreeSet<>(Comparator.comparingInt(Person::getAge).thenComparing(Person::getName)))`。

### 1.3 Map 键值排序、极值查找与自定义合并策略 (`Map.merge`)

#### 题目描述
给定两个 `Map<String, Integer>`，实现以下三个高频操作：
1. **合并两个 Map**：若 key 仅存在于一个 Map 则直接保留；若同时存在则**取较大值**（要求使用 `Map.merge`，不写显式 `if-else`）。
2. **查找极值 Key**：找出合并后 Map 中 Value 最大对应的 Key。
3. **按 Value 降序 / 按 Key 升序排序**：输出排序后的键值对列表。

#### 参考答案

```java
import java.util.*;

public class MapOperationsDemo {

    // 1. 使用 Map.merge 合并两个 Map 并取较大值
    public static Map<String, Integer> mergeWithMax(Map<String, Integer> map1, Map<String, Integer> map2) {
        Map<String, Integer> result = new HashMap<>(map1);
        map2.forEach((key, val) -> result.merge(key, val, Math::max));
        return result;
    }

    // 2. 查找最大值对应的 Key
    public static String findKeyWithMaxValue(Map<String, Integer> map) {
        return map.entrySet().stream()
                .max(Map.Entry.comparingByValue())
                .map(Map.Entry::getKey)
                .orElse(null);
    }

    // 3. 按 Value 降序排序返回 LinkedHashMap（保留排序顺序）
    public static Map<String, Integer> sortByValueDesc(Map<String, Integer> map) {
        Map<String, Integer> sortedMap = new LinkedHashMap<>();
        map.entrySet().stream()
                .sorted(Map.Entry.<String, Integer>comparingByValue().reversed())
                .forEachOrdered(e -> sortedMap.put(e.getKey(), e.getValue()));
        return sortedMap;
    }

    public static void main(String[] args) {
        Map<String, Integer> map1 = Map.of("a", 1, "b", 3, "c", 5);
        Map<String, Integer> map2 = Map.of("b", 4, "c", 2, "d", 6);

        Map<String, Integer> merged = mergeWithMax(map1, map2);
        System.out.println("合并结果: " + merged); // {a=1, b=4, c=5, d=6}
        System.out.println("最大值的Key: " + findKeyWithMaxValue(merged)); // d
        System.out.println("按值降序: " + sortByValueDesc(merged)); // {d=6, c=5, b=4, a=1}
    }
}
```

### 1.4 集合条件安全删除 (`removeIf` vs `Iterator`)

#### 题目描述
1. 给定整数列表，原地移除所有小于阈值 `threshold` 的元素。
2. 给定 `Map<String, Integer>`，原地移除所有值小于等于 `threshold` 的条目。

> **⚠️ 原文档 Bug 勘误**：原 ChatGPT 代码直接对 `Arrays.asList(1, 5, 3, 7, 9, 2)` 调用 `removeIf()`。注意 `Arrays.asList()` 返回的是 `java.util.Arrays$ArrayList`（固定长度内部类），调用 `remove/removeIf/add` 会直接抛出 `UnsupportedOperationException`！必须先包装为 `new ArrayList<>(...)`。

#### 参考答案

```java
import java.util.*;

public class SafeRemoveDemo {
    public static void main(String[] args) {
        // 必须使用可变集合 ArrayList 包装 Arrays.asList
        List<Integer> numbers = new ArrayList<>(Arrays.asList(1, 5, 3, 7, 9, 2));
        int threshold = 5;

        // 方式 1（推荐，JDK 8+）：使用 Collection.removeIf
        numbers.removeIf(n -> n < threshold);
        System.out.println("List删除后: " + numbers); // [5, 7, 9]

        // 方式 2（传统）：使用 Iterator 显式移除（严禁在 foreach 循环中直接调 list.remove）
        // Iterator<Integer> it = numbers.iterator();
        // while (it.hasNext()) { if (it.next() < threshold) it.remove(); }

        // Map 条件删除：通过 entrySet().removeIf()
        Map<String, Integer> map = new HashMap<>(Map.of("apple", 10, "banana", 5, "cherry", 7));
        map.entrySet().removeIf(entry -> entry.getValue() <= 6);
        System.out.println("Map删除后: " + map); // {apple=10, cherry=7}
    }
}
```

### 1.5 多维复合索引结构设计 (`HashMap` + `TreeMap`)

#### 题目描述
1. **用户多维检索**：设计一个存储用户信息的结构，既能通过 `userId` 在 $O(1)$ 时间内快速查询用户，又能按 `userAge` 升序遍历所有用户。
2. **分组有序索引**：将字符串列表反转后，使用 `TreeMap` 统计每个长度对应的字符串列表，并按长度升序输出。

#### 参考答案

```java
import java.util.*;

public class MultiIndexCollectionDemo {
    record User(int userId, String userName, int userAge) {}

    public static void main(String[] args) {
        // 场景 1：HashMap 实现 O(1) 主键查询 + List 排序视图
        Map<Integer, User> userMap = new HashMap<>();
        List.of(new User(1, "Alice", 25), new User(2, "Bob", 22), new User(3, "Charlie", 30))
                .forEach(u -> userMap.put(u.userId(), u));

        System.out.println("查询 userId=2: " + userMap.get(2));
        List<User> sortedByAge = new ArrayList<>(userMap.values());
        sortedByAge.sort(Comparator.comparingInt(User::userAge));
        System.out.println("按年龄升序: " + sortedByAge);

        // 场景 2：LinkedList 反转 + TreeMap 按长度自然升序归类
        LinkedList<String> list = new LinkedList<>(Arrays.asList("apple", "banana", "cherry", "date"));
        Collections.reverse(list);
        TreeMap<Integer, List<String>> lengthMap = new TreeMap<>();
        for (String s : list) {
            lengthMap.computeIfAbsent(s.length(), k -> new ArrayList<>()).add(s);
        }
        System.out.println("按长度升序分组: " + lengthMap); // {4=[date], 5=[apple], 6=[cherry, banana]}
    }
}
```

### 1.6 手撕线程安全 LRU 缓存 (`LinkedHashMap`)

#### 题目描述
使用 `LinkedHashMap` 实现一个**线程安全的 LRU（最近最少使用）缓存**，支持 `get(key)` 和 `put(key, value)` 操作，最大容量为 `capacity`。当缓存满时自动淘汰最久未使用的条目。

#### 参考答案

```java
import java.util.*;

public class LRUCache<K, V> {
    private final int capacity;
    private final Map<K, V> cache;

    public LRUCache(int capacity) {
        if (capacity <= 0) throw new IllegalArgumentException("Capacity must be positive");
        this.capacity = capacity;
        // accessOrder = true 表示按访问顺序（get/put）维护双向链表，队头为最久未使用，队尾为最近使用
        this.cache = new LinkedHashMap<>(16, 0.75f, true) {
            @Override
            protected boolean removeEldestEntry(Map.Entry<K, V> eldest) {
                return size() > LRUCache.this.capacity;
            }
        };
    }

    public synchronized V get(K key) {
        return cache.get(key);
    }

    public synchronized void put(K key, V value) {
        cache.put(key, value);
    }

    @Override
    public synchronized String toString() {
        return cache.toString();
    }

    public static void main(String[] args) {
        LRUCache<Integer, String> lru = new LRUCache<>(2);
        lru.put(1, "A");
        lru.put(2, "B");
        lru.get(1);      // 访问 1，1 移至队尾（最近使用），2 成为最久未使用
        lru.put(3, "C"); // 容量超限，自动淘汰 key=2
        System.out.println(lru); // {1=A, 3=C}
    }
}
```

> **面试追问**：为什么 `get()` 方法也必须加锁？
> 因为当 `accessOrder = true` 时，`LinkedHashMap.get()` 会修改内部双向链表的节点指针顺序（`afterNodeAccess`），在多线程并发读时若不加锁会导致链表成环或数据不一致！

### 1.7 不可变集合与防御性拷贝安全发布

#### 题目描述
实现一个线程安全的配置类 `ImmutableConfig`，构造时接收外部传入的 `Map<String, String>` 或可变参数键值对，要求：
1. 外部修改原始传入的 Map 不影响内部状态（防御性拷贝）；
2. 对外提供的查询视图完全不可变（禁止修改）。

#### 参考答案

```java
import java.util.*;

public class ImmutableConfig {
    private final Map<String, String> config;

    // 方式 1：接收外部 Map（使用 Map.copyOf 实现防御性浅拷贝 + 不可变封装）
    public ImmutableConfig(Map<String, String> input) {
        // JDK 10+ 推荐：Map.copyOf 内部会拷贝一份数据并生成不可变 Map（不允许 null 键值）
        this.config = Map.copyOf(input);
        // 若需兼容含 null 的旧代码，必须先 new HashMap<>(input) 再套 unmodifiableMap：
        // this.config = Collections.unmodifiableMap(new HashMap<>(input));
    }

    // 方式 2：接收键值对可变参数并保持插入顺序
    public ImmutableConfig(String... keyValuePairs) {
        if (keyValuePairs.length % 2 != 0) {
            throw new IllegalArgumentException("Key-value pairs length must be even");
        }
        Map<String, String> temp = new LinkedHashMap<>();
        for (int i = 0; i < keyValuePairs.length; i += 2) {
            temp.put(keyValuePairs[i], keyValuePairs[i + 1]);
        }
        this.config = Collections.unmodifiableMap(temp);
    }

    public String get(String key) {
        return config.get(key);
    }

    public Set<String> getAllKeys() {
        return config.keySet(); // unmodifiableMap / Map.copyOf 的 keySet 天然不可变
    }

    public static void main(String[] args) {
        Map<String, String> raw = new HashMap<>();
        raw.put("timeout", "5000");
        ImmutableConfig cfg = new ImmutableConfig(raw);

        raw.put("timeout", "9999"); // 修改原始 Map 不影响 cfg
        System.out.println("timeout = " + cfg.get("timeout")); // 5000
    }
}
```

> **核心避坑点**：若直接写 `this.config = Collections.unmodifiableMap(input);`，它仅包装一层只读代理，调用方持有原 `input` 引用依然可以篡改底层数据！必须先 `new HashMap<>(input)` 或直接用 `Map.copyOf(input)`。

### 1.8 并发集合实战 (`ConcurrentHashMap` 原子累加与 `CopyOnWriteArrayList`)

#### 题目描述
1. 使用 `ConcurrentHashMap` 实现无锁线程安全的指标计数器 `SafeMetricsCounter`，支持 `increment(String key)`（不得使用 `synchronized` 或 `ReentrantLock`）。
2. 演示 `CopyOnWriteArrayList` 在多线程并发写入下的安全性与适用边界。

> **⚠️ 原文档 Bug 勘误**：原通义 `day06` 代码将 `computeIfAbsent(key, k -> 0)` 与 `computeIfPresent(key, (k, v) -> v + 1)` 拆成两行调用，两次调用之间非原子且多做一次哈希查找。应直接使用单步原子方法 `merge` 或 `computeIfAbsent + LongAdder`。

#### 参考答案

```java
import java.util.concurrent.*;
import java.util.concurrent.atomic.LongAdder;

public class ConcurrentCollectionsDemo {

    // 方案 A：使用 ConcurrentHashMap.merge 原子更新
    static class MergeCounter {
        private final ConcurrentHashMap<String, Integer> map = new ConcurrentHashMap<>();

        public void increment(String key) {
            map.merge(key, 1, Integer::sum); // 单步原子操作
        }

        public int get(String key) {
            return map.getOrDefault(key, 0);
        }
    }

    // 方案 B（高并发生产级首选）：ConcurrentHashMap + LongAdder（分段 CAS，避免热点 key 自旋冲突）
    static class HighConcurrencyCounter {
        private final ConcurrentHashMap<String, LongAdder> map = new ConcurrentHashMap<>();

        public void increment(String key) {
            map.computeIfAbsent(key, k -> new LongAdder()).increment();
        }

        public long get(String key) {
            LongAdder adder = map.get(key);
            return adder == null ? 0L : adder.sum();
        }
    }

    public static void main(String[] args) throws InterruptedException {
        HighConcurrencyCounter counter = new HighConcurrencyCounter();
        CopyOnWriteArrayList<String> cowList = new CopyOnWriteArrayList<>();
        CountDownLatch latch = new CountDownLatch(3);

        for (int i = 1; i <= 3; i++) {
            final int tid = i;
            new Thread(() -> {
                for (int j = 1; j <= 1000; j++) {
                    counter.increment("click");
                    if (j <= 5) cowList.add("T" + tid + "-" + j);
                }
                latch.countDown();
            }).start();
        }
        latch.await();
        System.out.println("click 最终计数: " + counter.get("click")); // 3000
        System.out.println("CopyOnWriteArrayList 大小: " + cowList.size()); // 15
    }
}
```

```java
    private int size = 0;

            }
        };
```

### 1.10 `ArrayList` vs `LinkedList` 性能对比与 `HashMap` 冲突原理验证

#### 核心原理速览
1. **`ArrayList` vs `LinkedList`**：
   - **尾部追加**：`ArrayList` 均摊 $O(1)$ 且具备 CPU 缓存行局部性优势，百万级添加远快于 `LinkedList`（每次需 `new Node` 分配堆内存）。
   - **中间按下标插入 `add(index, e)`**：`ArrayList` 需调用 `System.arraycopy` 搬移元素（$O(n)$）；`LinkedList` 需先折半遍历链表定位节点（$O(n)$），只有在已持有 `ListIterator` 的情况下插入才是 $O(1)$。
   - **随机访问与遍历**：`ArrayList` 索引访问 $O(1)$，远快于 `LinkedList`。
2. **`HashMap`（JDK 8+）核心机制**：
   - **扰动函数**：`(h = key.hashCode()) ^ (h >>> 16)`，将高 16 位特征混入低 16 位，降低小容量下 `(n - 1) & hash` 的碰撞率。
   - **树化双条件**：链表长度 $\ge 8$ **且** 数组桶容量 $\ge 64$ 时转为红黑树；若桶容量 $< 64$，优先触发 `resize()` 扩容而非树化。
   - **退化条件**：扩容拆分或删除节点使红黑树节点数 $\le 6$ 时退化回单向链表。

### 2.6 手撕自定义收集器 (`Collector` 四要素实战)

#### 题目描述
实现一个自定义 `Collector<String, Map<Character, StringBuilder>, Map<Character, String>>`，将字符串列表按**首字母（小写）分组**，同组字符串使用 `" | "` 拼接。同时给出内置 `Collectors.groupingBy + joining` 的等价简化写法。

#### 参考答案

```java
import java.util.*;
import java.util.function.*;
import java.util.stream.Collector;
import java.util.stream.Collectors;

public class CustomCollectorDemo {

    // 方式 1：手写 Collector 接口四要素（supplier, accumulator, combiner, finisher）
    public static Collector<String, Map<Character, StringBuilder>, Map<Character, String>> groupAndJoinCollector() {
        return new Collector<>() {
            @Override
            public Supplier<Map<Character, StringBuilder>> supplier() {
                return HashMap::new;
            }

            @Override
            public BiConsumer<Map<Character, StringBuilder>, String> accumulator() {
                return (map, word) -> {
                    if (word == null || word.isEmpty()) return;
                    char key = Character.toLowerCase(word.charAt(0));
                    StringBuilder sb = map.computeIfAbsent(key, k -> new StringBuilder());
                    if (!sb.isEmpty()) sb.append(" | ");
                    sb.append(word);
                };
            }

            @Override
            public BinaryOperator<Map<Character, StringBuilder>> combiner() {
                return (map1, map2) -> {
                    map2.forEach((k, sb2) -> map1.merge(k, sb2, (sb1, s2) -> sb1.append(" | ").append(s2)));
                    return map1;
                };
            }

            @Override
            public Function<Map<Character, StringBuilder>, Map<Character, String>> finisher() {
                return map -> {
                    Map<Character, String> res = new HashMap<>();
                    map.forEach((k, sb) -> res.put(k, sb.toString()));
                    return res;
                };
            }

            @Override
            public Set<Characteristics> characteristics() {
                return Collections.unmodifiableSet(EnumSet.of(Characteristics.UNORDERED));
            }
        };
    }

    public static void main(String[] args) {
        List<String> words = List.of("apple", "banana", "Avocado", "cherry", "blueberry");

        // 使用自定义 Collector
        Map<Character, String> res1 = words.stream().collect(groupAndJoinCollector());
        System.out.println("自定义Collector: " + res1);

        // 方式 2：内置组合收集器（生产推荐）
        Map<Character, String> res2 = words.stream()
                .collect(Collectors.groupingBy(
                        w -> Character.toLowerCase(w.charAt(0)),
                        Collectors.joining(" | ")
                ));
        System.out.println("内置组合Collector: " + res2);
        // 输出: {a=apple | Avocado, b=banana | blueberry, c=cherry}
    }
}
```

### 3.1 数组原地反转与环形右移 K 位（三次反转法）

#### 题目描述
将一个整型数组中的所有元素向右循环移动 `k` 个位置（`k >= 0`）。
- **示例**：`nums = [1, 2, 3, 4, 5, 6, 7], k = 3` $\rightarrow$ `[5, 6, 7, 1, 2, 3, 4]`
- **要求**：原地修改数组，时间复杂度 $O(n)$，空间复杂度 $O(1)$。

#### 参考答案

```java
import java.util.Arrays;

public class RotateArrayDemo {

    // 方案 1（面试首选，O(1) 额外空间）：三次反转法
    public static void rotateInPlace(int[] nums, int k) {
        if (nums == null || nums.length <= 1) return;
        int n = nums.length;
        k %= n;
        if (k == 0) return;

        reverse(nums, 0, n - 1); // 1. 整体反转: [7, 6, 5, 4, 3, 2, 1]
        reverse(nums, 0, k - 1); // 2. 反转前 k 个: [5, 6, 7, 4, 3, 2, 1]
        reverse(nums, k, n - 1); // 3. 反转后 n-k 个: [5, 6, 7, 1, 2, 3, 4]
    }

    public static void reverse(int[] nums, int start, int end) {
        while (start < end) {
            int temp = nums[start];
            nums[start++] = nums[end];
            nums[end--] = temp;
        }
    }

    // 方案 2（工程便捷写法，O(n) 额外空间）：利用 System.arraycopy
    public static int[] rotateWithCopy(int[] nums, int k) {
        int n = nums.length;
        k %= n;
        int[] rotated = new int[n];
        System.arraycopy(nums, n - k, rotated, 0, k);
        System.arraycopy(nums, 0, rotated, k, n - k);
        return rotated;
    }

    public static void main(String[] args) {
        int[] nums = {1, 2, 3, 4, 5, 6, 7};
        rotateInPlace(nums, 3);
        System.out.println(Arrays.toString(nums)); // [5, 6, 7, 1, 2, 3, 4]
```

### 3.3 二维矩阵转置与原地顺时针旋转 90°

#### 题目描述
1. **通用矩阵转置**：将 $m \times n$ 的二维矩阵行列互换，返回 $n \times m$ 的新矩阵（含空数组边界校验）。
2. **方阵原地顺时针旋转 90°（LeetCode 48）**：给定 $n \times n$ 的二维方阵，不使用额外矩阵，**原地顺时针旋转 90 度**。

#### 参考答案

```java
import java.util.Arrays;

public class MatrixTransformDemo {

    // 1. 通用 m x n 矩阵转置
    public static int[][] transpose(int[][] matrix) {
        if (matrix == null || matrix.length == 0 || matrix[0].length == 0) {
            throw new IllegalArgumentException("输入矩阵不能为空");
        }
        int rows = matrix.length, cols = matrix[0].length;
        int[][] res = new int[cols][rows];
        for (int i = 0; i < rows; i++) {
            for (int j = 0; j < cols; j++) {
                res[j][i] = matrix[i][j];
            }
        }
        return res;
    }

    // 2. n x n 方阵原地顺时针旋转 90° = 主对角线转置 + 每行左右翻转
    public static void rotate90Clockwise(int[][] matrix) {
        int n = matrix.length;
        // Step 1: 沿主对角线翻转（matrix[i][j] <-> matrix[j][i]）
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                int temp = matrix[i][j];
                matrix[i][j] = matrix[j][i];
                matrix[j][i] = temp;
            }
        }
        // Step 2: 每一行左右对称翻转
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n / 2; j++) {
                int temp = matrix[i][j];
                matrix[i][j] = matrix[i][n - 1 - j];
                matrix[i][n - 1 - j] = temp;
            }
        }
    }

    public static void main(String[] args) {
        int[][] matrix = {
                {1, 2, 3},
                {4, 5, 6},
                {7, 8, 9}
        };
        rotate90Clockwise(matrix);
        for (int[] row : matrix) {
            System.out.println(Arrays.toString(row));
        }
        // 输出: [7, 4, 1], [8, 5, 2], [9, 6, 3]
    }
}
```

### 3.4 荷兰国旗问题 / 三色排序（三指针原地分区）

#### 题目描述
给定一个仅包含 `0`、`1`、`2` 的整型数组（LeetCode 75），请**一次遍历、原地排序**使得所有 `0` 在前，`1` 居中，`2` 在后（時間 $O(n)$，空间 $O(1)$）。

#### 参考答案

```java
import java.util.Arrays;

public class DutchNationalFlag {
    public static void sortColors(int[] nums) {
        // [0, low-1] 全为 0；[low, mid-1] 全为 1；[high+1, n-1] 全为 2
        int low = 0, mid = 0, high = nums.length - 1;
        while (mid <= high) {
            if (nums[mid] == 0) {
                swap(nums, low++, mid++);
            } else if (nums[mid] == 1) {
                mid++;
            } else {
                // 注意：从 high 换过来的元素尚未检查，故只执行 high--，mid 不能自增！
                swap(nums, mid, high--);
            }
        }
    }

    private static void swap(int[] arr, int i, int j) {
        int temp = arr[i];
        arr[i] = arr[j];
        arr[j] = temp;
    }

    public static void main(String[] args) {
        int[] nums = {2, 0, 2, 1, 1, 0};
        sortColors(nums);
        System.out.println(Arrays.toString(nums)); // [0, 0, 1, 1, 2, 2]
    }
}
```

### 3.7 两数之和、寻找第二大元素与第 K 大元素

#### 题目描述
1. **两数之和（LeetCode 1）**：在数组中找出和为 `target` 的两个数并返回其下标（要求单次遍历 $O(n)$）。
2. **寻找第二大元素**：单次遍历找出数组中严格小于最大值的第二大元素（若不存在则返回 `-1`）。
3. **寻找第 K 大元素（LeetCode 215）**：使用小顶堆 `PriorityQueue` 在 $O(n \log k)$ 时间内找出第 K 大元素。

#### 参考答案

```java
import java.util.*;

public class ArraySearchProblems {

    // 1. 两数之和：哈希表一次遍历 O(n)
    public static int[] twoSum(int[] nums, int target) {
        Map<Integer, Integer> idxMap = new HashMap<>();
        for (int i = 0; i < nums.length; i++) {
            int complement = target - nums[i];
            if (idxMap.containsKey(complement)) {
                return new int[]{idxMap.get(complement), i};
            }
            idxMap.put(nums[i], i);
        }
        return new int[]{-1, -1};
    }

    // 2. 单次遍历寻找严格第二大元素
    public static int findSecondLargest(int[] nums) {
        long first = Long.MIN_VALUE, second = Long.MIN_VALUE;
        for (int num : nums) {
            if (num > first) {
                second = first;
                first = num;
            } else if (num > second && num < first) {
                second = num;
            }
        }
        return second == Long.MIN_VALUE ? -1 : (int) second;
    }

    // 3. 寻找第 K 大元素：维护容量为 K 的小顶堆
    public static int findKthLargest(int[] nums, int k) {
        PriorityQueue<Integer> minHeap = new PriorityQueue<>(k);
        for (int num : nums) {
            if (minHeap.size() < k) {
                minHeap.offer(num);
            } else if (num > minHeap.peek()) {
                minHeap.poll();
                minHeap.offer(num);
            }
        }
        return minHeap.peek();
    }

    public static void main(String[] args) {
        System.out.println("两数之和下标: " + Arrays.toString(twoSum(new int[]{2, 7, 11, 15}, 9))); // [0, 1]
        System.out.println("第二大元素: " + findSecondLargest(new int[]{12, 35, 1, 10, 34, 1}));   // 34
        System.out.println("第2大元素: " + findKthLargest(new int[]{3, 2, 1, 5, 6, 4}, 2));         // 5
    }
}
```

### 3.8 滑动窗口最大值（单调双端队列 $O(n)$ 模板）

#### 题目描述
给定整数数组 `nums` 和滑动窗口大小 `k`，返回每个滑动窗口中的最大值（LeetCode 239，要求 $O(n)$ 时间复杂度）。

#### 参考答案

```java
import java.util.*;

public class SlidingWindowMaximum {
    public static int[] maxSlidingWindow(int[] nums, int k) {
        if (nums == null || k <= 0 || nums.length < k) return new int[0];
        int n = nums.length;
        int[] res = new int[n - k + 1];
        // 双端队列存储数组下标，对应元素值严格单调递减，队首始终为当前窗口最大值下标
        Deque<Integer> deque = new ArrayDeque<>();

        for (int i = 0; i < n; i++) {
            // 1. 队首滑出窗口左边界 (i - k) 时淘汰
            if (!deque.isEmpty() && deque.peekFirst() <= i - k) {
                deque.pollFirst();
            }
            // 2. 维护单调递减：队尾元素 <= 当前元素时全部淘汰
            while (!deque.isEmpty() && nums[deque.peekLast()] <= nums[i]) {
                deque.pollLast();
            }
            // 3. 当前下标入队尾
            deque.offerLast(i);
            // 4. 当窗口达到大小 k 时（i >= k - 1），记录队首最大值
            if (i >= k - 1) {
                res[i - k + 1] = nums[deque.peekFirst()];
            }
        }
        return res;
    }

    public static void main(String[] args) {
        int[] nums = {1, 3, -1, -3, 5, 3, 6, 7};
        System.out.println(Arrays.toString(maxSlidingWindow(nums, 3))); // [3, 3, 5, 5, 6, 7]
    }
}
```

```java
    private static volatile ConfigManager instance;

            synchronized (ConfigManager.class) {
                if (instance == null) {             // 第 2 次检查：防止多个线程同时通过第 1 次检查后重复创建
                    instance = new ConfigManager();
                }
            }
        }
        return instance;
    }
```

### 4.3 线程先后顺序控制（A 执行完再执行 B 的三种标准写法）

#### 题目描述
创建线程 A（打印 1~10）和线程 B（打印 11~20），要求无论哪个线程先被操作系统调度，都必须保证**线程 A 完全执行结束后，线程 B 才开始执行**。

> **⚠️ 原文档致命 Bug 勘误**：
> 原豆包 `day01` 的 `synchronized` 和 `ReentrantLock` 写法中，**没有定义布尔状态变量 `aFinished`**，直接让线程 B 调用 `lock.wait()` / `condition.await()`。一旦线程 A 先抢到锁执行完并调用 `notify()`，后抢到锁的线程 B 再调用 `wait()` 将由于**错失通知信号（Lost Wakeup）而永久死锁**！下面给出正确的标准模板。

#### 参考答案

```java
import java.util.concurrent.CountDownLatch;
import java.util.concurrent.locks.Condition;
import java.util.concurrent.locks.ReentrantLock;

public class ThreadSequentialExecution {

    // 方式 1（最简洁推荐）：使用 CountDownLatch
    public static void runWithLatch() throws InterruptedException {
        CountDownLatch latch = new CountDownLatch(1);
        Thread threadA = new Thread(() -> {
            try {
                System.out.println("[Latch] 线程A执行 1~10 完毕");
            } finally {
                latch.countDown(); // 计数器减为 0，唤醒 B
            }
        });
        Thread threadB = new Thread(() -> {
            try {
                latch.await(); // 若 A 已完成则直接通过，绝无信号丢失风险
                System.out.println("[Latch] 线程B收到通知，开始执行 11~20");
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            }
        });
        threadB.start();
        threadA.start();
        threadB.join();
    }

    // 方式 2（正确手撕 wait/notify）：必须搭配 boolean 状态标志 + while 循环防虚假唤醒与信号丢失！
    private static boolean aFinished = false;
    private static final Object LOCK = new Object();

    public static void runWithWaitNotify() throws InterruptedException {
        Thread threadA = new Thread(() -> {
            synchronized (LOCK) {
                System.out.println("[Wait/Notify] 线程A执行 1~10 完毕");
                aFinished = true; // 关键：修改状态位
                LOCK.notifyAll();
            }
        });
        Thread threadB = new Thread(() -> {
            synchronized (LOCK) {
                while (!aFinished) { // 关键：若 A 已先执行完，aFinished 为 true，B 不会进入 wait() 死锁！
                    try {
                        LOCK.wait();
                    } catch (InterruptedException e) {
                        Thread.currentThread().interrupt();
                        return;
                    }
                }
                System.out.println("[Wait/Notify] 线程B开始执行 11~20");
            }
        });
        threadB.start();
        threadA.start();
        threadB.join();
    }

    // 方式 3（正确手撕 ReentrantLock + Condition）：同样必须配合状态变量
    private static boolean aDone = false;
    private static final ReentrantLock R_LOCK = new ReentrantLock();
    private static final Condition CONDITION = R_LOCK.newCondition();

    public static void runWithCondition() throws InterruptedException {
        Thread threadA = new Thread(() -> {
            R_LOCK.lock();
            try {
                System.out.println("[Condition] 线程A执行 1~10 完毕");
                aDone = true;
                CONDITION.signalAll();
            } finally {
                R_LOCK.unlock();
            }
        });
        Thread threadB = new Thread(() -> {
            R_LOCK.lock();
            try {
                while (!aDone) {
                    CONDITION.await();
                }
                System.out.println("[Condition] 线程B开始执行 11~20");
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            } finally {
                R_LOCK.unlock();
            }
        });
        threadB.start();
        threadA.start();
        threadB.join();
    }

    public static void main(String[] args) throws InterruptedException {
        runWithLatch();
        runWithWaitNotify();
        runWithCondition();
    }
}
```

### 4.4 多线程交替打印问题全解（双线程奇偶交替 & 三线程打印 ABC）

#### 题目描述
1. **双线程交替**：线程 A 与线程 B 严格交替打印 `1 2 1 2 ...`（或交替打印 `1~10` 的奇偶数）。
2. **三线程循环打印 ABC（大厂高频手撕）**：启动三个线程分别打印 `"A"`、`"B"`、`"C"`，循环 3 次，严格输出 `ABCABCABC`。

> **⚠️ 原文档致命 Bug 勘误**：
> 原 ChatGPT `day04` 题 4 在 `for` 循环中重复使用 `CountDownLatch(1)` 实现交替打印。**`CountDownLatch` 计数减到 0 后无法重置复用**，第 2 轮起完全失去同步作用！交替打印必须使用 `synchronized + 状态位`、`ReentrantLock + Condition` 或 `Semaphore` 信号量环。

#### 参考答案

```java
import java.util.concurrent.Semaphore;
import java.util.concurrent.locks.Condition;
import java.util.concurrent.locks.ReentrantLock;

public class AlternatingPrintAllInOne {

    // ==================== 场景 1：双线程交替打印 1~10（奇偶数） ====================
    static class TwoThreadOddEven {
        private int num = 1;
        private final Object lock = new Object();

        public void printOddEven() throws InterruptedException {
            Runnable task = () -> {
                while (true) {
                    synchronized (lock) {
                        if (num > 10) {
                            lock.notifyAll(); // 防止另一线程永久阻塞在最后一次 wait
                            break;
                        }
                        System.out.print(Thread.currentThread().getName() + ":" + num++ + " ");
                        lock.notifyAll();
                        try {
                            if (num <= 10) lock.wait();
                        } catch (InterruptedException e) {
                            Thread.currentThread().interrupt();
                        }
                    }
                }
            };
            Thread t1 = new Thread(task, "T1");
            Thread t2 = new Thread(task, "T2");
            t1.start(); t2.start();
            t1.join(); t2.join();
            System.out.println();
        }
    }

    // ==================== 场景 2：三线程按序打印 ABC（模板 A：synchronized + 状态取模） ====================
    static class PrintABCWithSync {
        private int state = 0; // state % 3 == 0 打印 A, 1 打印 B, 2 打印 C

        public void print(int targetState, String ch, int loops) {
            for (int i = 0; i < loops; i++) {
                synchronized (this) {
                    while (state % 3 != targetState) {
                        try {
                            wait();
                        } catch (InterruptedException e) {
                            Thread.currentThread().interrupt();
                            return;
                        }
                    }
                    System.out.print(ch);
                    state++;
                    notifyAll();
                }
            }
        }
    }

    // ==================== 场景 3：三线程按序打印 ABC（模板 B：ReentrantLock + 3个 Condition 精准唤醒） ====================
    static class PrintABCWithCondition {
        private int state = 0;
        private final ReentrantLock lock = new ReentrantLock();
        private final Condition[] conditions = {lock.newCondition(), lock.newCondition(), lock.newCondition()};

        public void print(int targetState, String ch, int loops) {
            for (int i = 0; i < loops; i++) {
                lock.lock();
                try {
                    while (state % 3 != targetState) {
                        conditions[targetState].await();
                    }
                    System.out.print(ch);
                    state++;
                    // 精准唤醒下一个线程对应的 Condition，避免 notifyAll 的惊群开销
                    conditions[state % 3].signal();
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                } finally {
                    lock.unlock();
                }
            }
        }
    }

    // ==================== 场景 4：三线程按序打印 ABC（模板 C：Semaphore 信号量传递，最易默写） ====================
    static class PrintABCWithSemaphore {
        private final Semaphore semA = new Semaphore(1); // A 初始有 1 个许可
        private final Semaphore semB = new Semaphore(0);
        private final Semaphore semC = new Semaphore(0);

        public void startPrint(int loops) throws InterruptedException {
            Thread tA = new Thread(() -> print("A", semA, semB, loops));
            Thread tB = new Thread(() -> print("B", semB, semC, loops));
            Thread tC = new Thread(() -> print("C", semC, semA, loops));
            tA.start(); tB.start(); tC.start();
            tA.join(); tB.join(); tC.join();
            System.out.println();
        }

        private void print(String ch, Semaphore current, Semaphore next, int loops) {
            for (int i = 0; i < loops; i++) {
                try {
                    current.acquire();
                    System.out.print(ch);
                    next.release(); // 释放下一个线程的许可
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                }
            }
        }
    }

    public static void main(String[] args) throws InterruptedException {
        new TwoThreadOddEven().printOddEven(); // T1:1 T2:2 T1:3 ... T2:10

        PrintABCWithSync syncPrinter = new PrintABCWithSync();
        Thread a = new Thread(() -> syncPrinter.print(0, "A", 3));
        Thread b = new Thread(() -> syncPrinter.print(1, "B", 3));
        Thread c = new Thread(() -> syncPrinter.print(2, "C", 3));
        a.start(); b.start(); c.start();
        a.join(); b.join(); c.join();
        System.out.println(); // ABCABCABC

        new PrintABCWithSemaphore().startPrint(3); // ABCABCABC
    }
}
```

### 4.5 手撕生产者-消费者模型（`wait/notifyAll` vs `ReentrantLock + Condition`）

#### 题目描述
手写一个线程安全的有界阻塞队列 `BoundedBuffer<T>`（容量为 3）：
- 缓冲区满时生产者阻塞等待，空时消费者阻塞等待；
- 分别给出 `synchronized + wait/notifyAll` 和 `ReentrantLock + 双 Condition` 两种标准实现。

#### 参考答案

```java
import java.util.ArrayDeque;
import java.util.Queue;
import java.util.concurrent.locks.Condition;
import java.util.concurrent.locks.ReentrantLock;

public class ProducerConsumerHandwritten {

    // 实现 1：synchronized + wait/notifyAll
    static class SyncBoundedBuffer<T> {
        private final Queue<T> queue = new ArrayDeque<>();
        private final int capacity;

        public SyncBoundedBuffer(int capacity) { this.capacity = capacity; }

        public synchronized void put(T item) throws InterruptedException {
            while (queue.size() == capacity) { // 必须使用 while 防虚假唤醒
                wait();
            }
            queue.offer(item);
            notifyAll(); // 必须使用 notifyAll()，若用 notify() 可能只唤醒同类生产者导致死锁！
        }

        public synchronized T take() throws InterruptedException {
            while (queue.isEmpty()) {
                wait();
            }
            T item = queue.poll();
            notifyAll();
            return item;
        }
    }

    // 实现 2（推荐，同 ArrayBlockingQueue 底层原理）：ReentrantLock + notFull/notEmpty 双 Condition
    static class LockBoundedBuffer<T> {
        private final Queue<T> queue = new ArrayDeque<>();
        private final int capacity;
        private final ReentrantLock lock = new ReentrantLock();
        private final Condition notFull = lock.newCondition();
        private final Condition notEmpty = lock.newCondition();

        public LockBoundedBuffer(int capacity) { this.capacity = capacity; }

        public void put(T item) throws InterruptedException {
            lock.lock();
            try {
                while (queue.size() == capacity) {
                    notFull.await();
                }
                queue.offer(item);
                notEmpty.signal(); // 精准唤醒等待消费的线程
            } finally {
                lock.unlock();
            }
        }

        public T take() throws InterruptedException {
            lock.lock();
            try {
                while (queue.isEmpty()) {
                    notEmpty.await();
                }
                T item = queue.poll();
                notFull.signal(); // 精准唤醒等待生产的线程
                return item;
            } finally {
                lock.unlock();
            }
        }
    }

    public static void main(String[] args) throws InterruptedException {
        LockBoundedBuffer<Integer> buffer = new LockBoundedBuffer<>(3);
        Thread producer = new Thread(() -> {
            try {
                for (int i = 1; i <= 6; i++) {
                    buffer.put(i);
                    System.out.println("Produced: " + i);
                }
            } catch (InterruptedException e) { Thread.currentThread().interrupt(); }
        });
        Thread consumer = new Thread(() -> {
            try {
                for (int i = 1; i <= 6; i++) {
                    System.out.println("Consumed: " + buffer.take());
                }
            } catch (InterruptedException e) { Thread.currentThread().interrupt(); }
        });
        producer.start();
        consumer.start();
        producer.join();
        consumer.join();
    }
}
```

### 4.7 JUC 同步器实战：`Semaphore` 限流、`CyclicBarrier` 协同与 `ForkJoinPool` 分治

#### 题目描述
1. **`Semaphore` 并发限流器**：5 个线程并发访问资源，限制同一时刻最多允许 3 个线程同时访问。
2. **`CyclicBarrier` 多阶段屏障**：3 个子任务线程全部准备就绪后同时启动执行，且全部执行完毕后触发汇总回调。
3. **`ForkJoinPool` 分治计算**：继承 `RecursiveTask<Long>` 分治计算 $\sum_{i=1}^{10} i!$（阶乘累加和）。

> **⚠️ 原文档数学错误修正**：原 Grok `day07` 题 3 将 $1! + 2! + \dots + 10!$ 的预期结果错写成 `3628800`（那是单独 $10!$ 的值），实际阶乘累加和应为 `4037913`。

#### 参考答案

```java
import java.util.concurrent.*;

public class JucSynchronizersDemo {

    // 1. Semaphore 限流器
    public static void testSemaphore() throws InterruptedException {
        Semaphore semaphore = new Semaphore(3); // 最多 3 个并发许可
        CountDownLatch doneLatch = new CountDownLatch(5);
        for (int i = 1; i <= 5; i++) {
            final int id = i;
            new Thread(() -> {
                try {
                    semaphore.acquire();
                    System.out.println("线程" + id + " 获得许可，正在访问资源...");
                    TimeUnit.MILLISECONDS.sleep(100);
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                } finally {
                    semaphore.release(); // 必须在 finally 中释放许可
                    doneLatch.countDown();
                }
            }).start();
        }
        doneLatch.await();
    }

    // 2. CyclicBarrier 多阶段同步（可循环复用）
    public static void testCyclicBarrier() throws InterruptedException {
        CountDownLatch endLatch = new CountDownLatch(3);
        CyclicBarrier barrier = new CyclicBarrier(3, () ->
                System.out.println(">>> [BarrierAction] 阶段屏障全员到达！")
        );
        for (String name : new String[]{"用户注册", "发送邮件", "数据库落库"}) {
            new Thread(() -> {
                try {
                    System.out.println(name + " 准备就绪");
                    barrier.await(); // 第 1 道屏障：全员就绪后同时开跑
                    System.out.println(name + " 执行完成");
                    barrier.await(); // 第 2 道屏障：全员完成后触发汇总（体现 CyclicBarrier 可复用性）
                } catch (Exception e) {
                    Thread.currentThread().interrupt();
                } finally {
                    endLatch.countDown();
                }
            }).start();
        }
        endLatch.await();
    }

    // 3. ForkJoinPool 分治计算 1! + 2! + ... + n!
    static class FactorialSumTask extends RecursiveTask<Long> {
        private static final int THRESHOLD = 2;
        private final int start, end;

        FactorialSumTask(int start, int end) {
            this.start = start;
            this.end = end;
        }

        @Override
        protected Long compute() {
            if (end - start <= THRESHOLD) {
                long sum = 0;
                for (int i = start; i <= end; i++) sum += factorial(i);
                return sum;
            }
            int mid = start + (end - start) / 2;
            FactorialSumTask left = new FactorialSumTask(start, mid);
            FactorialSumTask right = new FactorialSumTask(mid + 1, end);
            left.fork(); // 异步压入工作窃取队列
            long rightRes = right.compute(); // 当前线程直接计算右半部分，减少一次线程切换开销
            return rightRes + left.join();
        }

        private long factorial(int n) {
            long fact = 1;
            for (int i = 2; i <= n; i++) fact *= i;
            return fact;
        }
    }

    public static void main(String[] args) throws Exception {
        testSemaphore();
        testCyclicBarrier();
        try (ForkJoinPool pool = new ForkJoinPool()) {
            long sum = pool.invoke(new FactorialSumTask(1, 10));
            System.out.println("1! + 2! + ... + 10! = " + sum); // 4037913
        }
    }
}
```

### 5.1 泛型类 `Pair<T>` 与受限泛型方法 `<T extends Comparable<T>>`

#### 题目描述

2. 编写受限泛型方法 `<T extends Comparable<T>> T findMax(List<T> list)`，返回任意实现了 `Comparable` 的列表中的最大元素。

#### 参考答案

```java
import java.util.Arrays;
import java.util.List;

public class GenericPracticeDemo {

    static class Pair<T> {
        private T first;
        private T second;

        public Pair(T first, T second) {
            this.first = first;
            this.second = second;
        }

        public T getFirst() { return first; }
        public T getSecond() { return second; }

        public void swap() {
            T temp = first;
            first = second;
            second = temp;
        }

        @Override
        public String toString() {
            return "Pair(" + first + ", " + second + ")";
        }
    }

    // 受限泛型上界：确保元素具备 compareTo 比较能力
    public static <T extends Comparable<? super T>> T findMax(List<T> list) {
        if (list == null || list.isEmpty()) {
            throw new IllegalArgumentException("列表不能为空");
        }
        T max = list.get(0);
        for (int i = 1; i < list.size(); i++) {
            T current = list.get(i);
            if (current.compareTo(max) > 0) {
                max = current;
            }
        }
        return max;
    }

    public static void main(String[] args) {
        Pair<String> pair = new Pair<>("Hello", "World");
        pair.swap();
        System.out.println("交换后: " + pair); // Pair(World, Hello)

        System.out.println("最大整数: " + findMax(Arrays.asList(3, 1, 4, 1, 5))); // 5
        System.out.println("最大字符串: " + findMax(Arrays.asList("banana", "apple", "cherry"))); // cherry
    }
}
```

```java
import java.io.*;
import java.nio.ByteBuffer;
import java.nio.channels.FileChannel;
import java.nio.charset.StandardCharsets;
import java.nio.file.*;

public class BioAndNioFileDemo {

    // 1. BIO 字符缓冲流按行写入与读取
    public static void bioReadWrite(Path path) throws IOException {
        try (BufferedWriter writer = Files.newBufferedWriter(path, StandardCharsets.UTF_8)) {
            writer.write("Name,Age");
            writer.newLine();
            writer.write("Alice,30");
        }
        try (BufferedReader reader = Files.newBufferedReader(path, StandardCharsets.UTF_8)) {
            String line;
            while ((line = reader.readLine()) != null) {
                System.out.println("[BIO读取] " + line);
            }
        }
    }

    // 2. NIO FileChannel + ByteBuffer 标准读写
    public static void nioReadWrite(Path path, String content) throws IOException {
        byte[] bytes = content.getBytes(StandardCharsets.UTF_8);

        // 写入通道
        try (FileChannel writeChannel = FileChannel.open(path,
                StandardOpenOption.CREATE, StandardOpenOption.WRITE, StandardOpenOption.TRUNCATE_EXISTING)) {
            ByteBuffer writeBuf = ByteBuffer.allocate(bytes.length);
            writeBuf.put(bytes); // 1. 写入 Buffer
            writeBuf.flip();     // 2. 切换为读模式 (limit = position, position = 0)
            while (writeBuf.hasRemaining()) {
                writeChannel.write(writeBuf); // 3. 从 Buffer 写入 Channel
            }
        }

        // 从通道读取
        try (FileChannel readChannel = FileChannel.open(path, StandardOpenOption.READ)) {
            ByteBuffer readBuf = ByteBuffer.allocate(1024); // ByteBuffer 不实现 AutoCloseable，必须在 try 块内声明
            int bytesRead = readChannel.read(readBuf);
            if (bytesRead != -1) {
                readBuf.flip(); // 切换为读模式
                byte[] data = new byte[readBuf.remaining()];
                readBuf.get(data);
                System.out.println("[NIO读取] " + new String(data, StandardCharsets.UTF_8));
                readBuf.clear(); // 清空重置以便下次复用
            }
        }
    }

    public static void main(String[] args) throws IOException {
        Path tempFile = Paths.get("nio_temp_test.txt");
        try {
            nioReadWrite(tempFile, "Hello NIO! 你好，NIO！");
        } finally {
            Files.deleteIfExists(tempFile);
        }
    }
}
```

### 6.1 一维前缀和与二维前缀和（子区域 $O(1)$ 查询）

#### 一、 核心思想与定义
**用空间换时间**：通过 $O(n)$ 或 $O(m \times n)$ 的预处理构建前缀和数组，使任意区间/子矩阵的求和查询降至 **$O(1)$**。
- **一维前缀和**：`pre[i] = nums[0] + ... + nums[i - 1]`，闭区间 `[left, right]` 之和为：
  $$\text{sum}(left, right) = pre[right + 1] - pre[left]$$
- **二维前缀和**（LeetCode 304）：设原矩阵为 $m \times n$，定义 `(m + 1) × (n + 1)` 的数组 `preSum`（第 0 行和第 0 列全为 0，免去边界判断），其中 `preSum[i][j]` 表示以 `(0, 0)` 为左上角、`(i - 1, j - 1)` 为右下角的子矩阵元素之和。

#### 二、 容斥原理图解与核心公式

```text
+-----------+-----------+
|     A     |     B     |
| (r1, c1)  | (r1, c2+1)|
+-----------+-----------+
|     C     |     D     |  <-- D 为目标子矩阵 [r1..r2][c1..c2]
|(r2+1, c1) |(r2+1,c2+1)|
+-----------+-----------+
```

1. **构建递推公式**：
   $$preSum[i][j] = matrix[i-1][j-1] + preSum[i-1][j] + preSum[i][j-1] - preSum[i-1][j-1]$$
   *(注：也可在每行内维护行累加和 `rowSum += matrix[i-1][j-1]`，则 `preSum[i][j] = preSum[i-1][j] + rowSum`，减少一次数组寻址与减法运算。)*
2. **查询子矩阵 `(r1, c1)` 到 `(r2, c2)`（0-indexed 闭区间）公式**：
   $$\text{sumRegion}(r_1, c_1, r_2, c_2) = preSum[r_2+1][c_2+1] - preSum[r_1][c_2+1] - preSum[r_2+1][c_1] + preSum[r_1][c_1]$$

#### 三、 完整 Java 实现

```java
public class PrefixSum1DAnd2D {

    // 1. 一维前缀和模板 (LeetCode 303)
    static class NumArray {
        private final int[] pre;

        public NumArray(int[] nums) {
            pre = new int[nums.length + 1];
            for (int i = 0; i < nums.length; i++) {
                pre[i + 1] = pre[i] + nums[i];
            }
        }

        public int sumRange(int left, int right) {
            return pre[right + 1] - pre[left];
        }
    }

    // 2. 二维前缀和模板 (LeetCode 304)
    static class NumMatrix {
        private final int[][] preSum;

        public NumMatrix(int[][] matrix) {
            int m = matrix.length, n = matrix[0].length;
            preSum = new int[m + 1][n + 1];
            for (int i = 1; i <= m; i++) {
                int rowSum = 0; // 行前缀和常数级优化
                for (int j = 1; j <= n; j++) {
                    rowSum += matrix[i - 1][j - 1];
                    preSum[i][j] = preSum[i - 1][j] + rowSum;
                }
            }
        }

        public int sumRegion(int r1, int c1, int r2, int c2) {
            return preSum[r2 + 1][c2 + 1]
                 - preSum[r1][c2 + 1]
                 - preSum[r2 + 1][c1]
                 + preSum[r1][c1];
        }
    }
}
```

### 6.2 一维差分与二维差分数组（区间/子矩阵 $O(1)$ 批量增减）

#### 一、 核心思想：前缀和的逆运算
当需要对数组或矩阵进行**多次区间/子矩阵加减同一个值 `val`，最后统一查询最终结果**时，暴力更新耗时 $O(k \cdot n)$，而**差分数组**每次标记仅需 **$O(1)$**，最后做一次前缀和即可在 $O(n)$ 或 $O(m \times n)$ 内还原最终结果。
> **一句话区分**：**前缀和用于“读优化”（多次查区间和），差分用于“写优化”（多次区间增减）**；若既要动态单点/区间修改又要实时查询区间和，则需使用**树状数组（Fenwick Tree）**或**线段树**。

#### 二、 一维差分与二维差分公式
1. **一维差分（LeetCode 1109 航班预订统计）**：
   - 定义：`diff[0] = a[0]`，`diff[i] = a[i] - a[i - 1]`。
   - 对闭区间 `[l, r]` 全部加 `val`：`diff[l] += val; if (r + 1 < n) diff[r + 1] -= val;`
   - 还原：对 `diff` 求一维前缀和。
2. **二维差分（LeetCode 2536 子矩阵元素加 1）**：
   - 记忆口诀：**“左上加，右上减，左下减，右下加”**。
   - 对子矩阵 `(r1, c1)` 到 `(r2, c2)` 全部加 `val`：
     ```java
     diff[r1][c1]         += val; // 从 (r1, c1) 开始产生影响
     diff[r1][c2 + 1]     -= val; // 抵消右侧越界区域影响
     diff[r2 + 1][c1]     -= val; // 抵消下侧越界区域影响
     diff[r2 + 1][c2 + 1] += val; // 补回右下角被重复减去两次的区域
     ```
   - 还原：对 `diff` 求二维前缀和。

#### 三、 二维差分完整 Java 模板（带边界保护）

```java
public class Diff2D {
    private final int[][] diff;
    private final int m, n;

    public Diff2D(int m, int n) {
        this.m = m;
        this.n = n;
        // 分配 (m + 2) x (n + 2) 避免 r2 + 1 或 c2 + 1 越界判断
        this.diff = new int[m + 2][n + 2];
    }

    // O(1) 标记子矩阵 [r1..r2][c1..c2] 增加 val（0-indexed 闭区间）
    public void add(int r1, int c1, int r2, int c2, int val) {
        diff[r1][c1] += val;
        diff[r1][c2 + 1] -= val;
        diff[r2 + 1][c1] -= val;
        diff[r2 + 1][c2 + 1] += val;
    }

    // O(m * n) 二维前缀和还原最终矩阵
    public int[][] getResult() {
        int[][] res = new int[m][n];
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                res[i][j] = diff[i][j];
                if (i > 0) res[i][j] += res[i - 1][j];
                if (j > 0) res[i][j] += res[i][j - 1];
                if (i > 0 && j > 0) res[i][j] -= res[i - 1][j - 1];
            }
        }
        return res;
    }
}
```

### 6.3 滑动窗口通用框架与经典例题（LC 3、LC 76、固定窗口）

#### 一、 识别特征与通用模板

```java
import java.util.*;

public class SlidingWindowClassics {

    // 例 1：固定窗口 —— 长度为 k 的连续子数组最大和
    public static int maxSumFixedWindow(int[] nums, int k) {
        int sum = 0;
        for (int i = 0; i < k; i++) sum += nums[i];
        int maxSum = sum;
        for (int i = k; i < nums.length; i++) {
            sum += nums[i] - nums[i - k]; // 右进左出
            maxSum = Math.max(maxSum, sum);
        }
        return maxSum;
    }

    // 例 2：可变窗口求最长 —— 无重复字符的最长子串 (LeetCode 3)
    public static int lengthOfLongestSubstring(String s) {
        int[] freq = new int[128]; // 替代 HashSet，常数性能极佳
        int left = 0, maxLen = 0;
        for (int right = 0; right < s.length(); right++) {
            char c = s.charAt(right);
            freq[c]++;
            while (freq[c] > 1) { // 存在重复字符，收缩左边界
                freq[s.charAt(left++)]--;
            }
            maxLen = Math.max(maxLen, right - left + 1);
        }
        return maxLen;
    }

    // 例 3：可变窗口求最短 —— 最小覆盖子串 (LeetCode 76, Hard)
    public static String minWindow(String s, String t) {
        int[] need = new int[128];
        int[] window = new int[128];
        int requiredKinds = 0;
        for (char c : t.toCharArray()) {
            if (need[c] == 0) requiredKinds++;
            need[c]++;
        }

        int left = 0, validKinds = 0;
        int start = 0, minLen = Integer.MAX_VALUE;

        for (int right = 0; right < s.length(); right++) {
            char c = s.charAt(right);
            if (need[c] > 0) {
                window[c]++;
                if (window[c] == need[c]) validKinds++;
            }
            // 当窗口已涵盖 t 所有字符时，收缩左边界寻找最短解
            while (validKinds == requiredKinds) {
                if (right - left + 1 < minLen) {
                    start = left;
                    minLen = right - left + 1;
                }
                char d = s.charAt(left++);
                if (need[d] > 0) {
                    if (window[d] == need[d]) validKinds--;
                    window[d]--;
                }
            }
        }
        return minLen == Integer.MAX_VALUE ? "" : s.substring(start, start + minLen);
    }
}
```

### 6.4 动态规划滚动数组空间压缩术

#### 一、 核心法则与遍历方向（必背）
当 DP 状态仅依赖上一层或前几个状态时，可通过滚动数组将空间复杂度从 $O(n \times m)$ 压缩至 $O(m)$ 甚至 $O(1)$：

| 经典问题 | 原始二维转移依赖 | 滚动后空间 | 一维内层遍历方向与关键细节 |
| :--- | :--- | :--- | :--- |
| **斐波那契 / 爬楼梯** | `dp[i]` 依赖 `dp[i-1], dp[i-2]` | $O(1)$ | 仅需两个整型变量 `a, b` 交替滚动 |
| **0-1 背包** | `dp[i][w]` 依赖上一行 `dp[i-1][w - weight[i]]` | $O(W)$ | **必须逆序遍历容量** `w: W -> weight[i]`，防止上一轮状态被提前覆盖 |
| **完全背包** | `dp[i][w]` 依赖本行 `dp[i][w - weight[i]]` | $O(W)$ | **必须正序遍历容量** `w: weight[i] -> W`（因为每种物品可无限重复选） |
| **最长公共子序列 (LCS)** | 依赖正上方 `dp[i-1][j]`、左方 `dp[i][j-1]`、左上角 `dp[i-1][j-1]` | $O(n)$ | **正序遍历** + 用临时变量 `prev` 保存被覆盖前的左上角 `dp[i-1][j-1]` |

#### 二、 核心代码实现

```java
public class RollingArrayDP {

    // 1. 0-1 背包一维滚动优化（逆序遍历容量）
    public static int zeroOneKnapsack(int[] weights, int[] values, int W) {
        int[] dp = new int[W + 1];
        for (int i = 0; i < weights.length; i++) {
            for (int w = W; w >= weights[i]; w--) { // 逆序！
                dp[w] = Math.max(dp[w], dp[w - weights[i]] + values[i]);
            }
        }
        return dp[W];
    }

    // 2. 最长公共子序列 LCS 一维滚动优化（正序 + prev 保存左上角）
    public static int longestCommonSubsequence(String s1, String s2) {
        int m = s1.length(), n = s2.length();
        int[] dp = new int[n + 1];
        for (int i = 1; i <= m; i++) {
            int prev = 0; // 保存 dp[i-1][j-1]
            for (int j = 1; j <= n; j++) {
                int temp = dp[j]; // 暂存未更新的 dp[j]（即 dp[i-1][j]），供 j+1 轮作左上角 prev
                if (s1.charAt(i - 1) == s2.charAt(j - 1)) {
                    dp[j] = prev + 1;
                } else {
                    dp[j] = Math.max(dp[j], dp[j - 1]);
                }
                prev = temp;
            }
        }
        return dp[n];
    }

    // 3. 含冷冻期的最佳买卖股票时机 (LeetCode 309)：状态机 O(1) 空间滚动
    public static int maxProfitWithCooldown(int[] prices) {
        int hold = -prices[0], sold = 0, rest = 0;
        for (int i = 1; i < prices.length; i++) {
            int nextHold = Math.max(hold, rest - prices[i]);
            int nextSold = hold + prices[i];
            int nextRest = Math.max(rest, sold);
            hold = nextHold;
            sold = nextSold;
            rest = nextRest;
        }
        return Math.max(sold, rest);
    }
}
```

### 6.5 位运算核心技巧与状态压缩 DP

#### 一、 高频位运算口诀总表

| 操作目标 | 位运算表达式 | 核心原理与经典应用 |
| :--- | :--- | :--- |
| **判断奇偶** | `(n & 1) == 1`（奇）/ `== 0`（偶） | 直接检查二进制最低位，替代取模 `% 2` |
| **消除最低位的 1** | `n & (n - 1)` | 统计二进制中 1 的个数（LeetCode 191 Brian Kernighan 算法） |
| **判断是否为 2 的幂** | `n > 0 && (n & (n - 1)) == 0` | 2 的幂二进制仅含一个 1（LeetCode 231） |
| **提取最低位的 1 (lowbit)** | `n & -n` | `-n` 为取反加 1 补码，树状数组与双唯一数分组核心（LeetCode 260） |
| **异或找唯一数** | `single ^= x` | 利用 `a ^ a = 0` 且 `0 ^ x = x`（LeetCode 136） |
| **第 `i` 位 置1 / 清0 / 翻转 / 检查** | `n \| (1 << i)` / `n & ~(1 << i)` / `n ^ (1 << i)` / `((n >> i) & 1) == 1` | 位图（BitMap）与状态压缩基础操作 |
| **不溢出求平均值** | `(x & y) + ((x ^ y) >> 1)` 或 `l + ((r - l) >>> 1)` | 二分查找防 `l + r` 整型溢出 |

#### 二、 高阶实战：异或找两个唯一数 & 位掩码枚举子集

```java
public class BitManipulationTricks {

    // 1. 数组中恰有两个元素只出现一次，其余均出现两次，O(n) 时间 O(1) 空间找出它们 (LeetCode 260)
    public static int[] singleNumberIII(int[] nums) {
        int xorAll = 0;
        for (int x : nums) xorAll ^= x;
        // 提取两个目标数异或结果的最低位 1（说明两数在该二进制位上一个是 0、一个是 1）
        int lowbit = xorAll & -xorAll;
        int a = 0, b = 0;
        for (int x : nums) {
            if ((x & lowbit) == 0) a ^= x;
            else b ^= x;
        }
        return new int[]{a, b};
    }

    // 2. 高效枚举位掩码 mask 的所有非空子集
    public static void enumerateSubsetsOfMask(int mask) {
        for (int sub = mask; sub > 0; sub = (sub - 1) & mask) {
            // sub 即为 mask 的一个非空真子集
        }
    }
}
```

### 6.6 贪心算法核心思想与五大经典模型

#### 一、 贪心成立的两大基石与反例警示
1. **贪心选择性质**：每一步采取局部最优选择，无需回溯即可导向全局最优解（无后效性）。
2. **最优子结构**：原问题的最优解包含子问题的最优解。
3. **经典失效反例**：硬币找零问题中，若币值系统为 `{1, 3, 4}`，目标凑 `6`：贪心会选 `4 + 1 + 1`（3 枚），而全局最优解是 `3 + 3`（2 枚），此时必须使用**动态规划（完全背包）**。

#### 二、 五大高频贪心模型模板

```java
import java.util.Arrays;

public class GreedyModels {

    // 模型 1：区间调度 / 最大不重叠区间数 (LeetCode 435) —— 核心：按结束时间升序排序！
    public static int eraseOverlapIntervals(int[][] intervals) {
        if (intervals.length == 0) return 0;
        // 使用 Integer.compare 防止减法溢出
        Arrays.sort(intervals, (a, b) -> Integer.compare(a[1], b[1]));
        int nonOverlapCount = 1;
        int lastEnd = intervals[0][1];
        for (int i = 1; i < intervals.length; i++) {
            if (intervals[i][0] >= lastEnd) {
                nonOverlapCount++;
                lastEnd = intervals[i][1];
            }
        }
        return intervals.length - nonOverlapCount;
    }

    // 模型 2：跳跃游戏 (LeetCode 55) —— 核心：维护当前能覆盖的最远边界 farthest
    public static boolean canJump(int[] nums) {
        int farthest = 0;
        for (int i = 0; i < nums.length; i++) {
            if (i > farthest) return false; // 当前位置不可达
            farthest = Math.max(farthest, i + nums[i]);
            if (farthest >= nums.length - 1) return true;
        }
        return true;
    }

    // 模型 3：买卖股票的最佳时机 II (LeetCode 122) —— 核心：收集所有正利润差分段
    public static int maxProfitII(int[] prices) {
        int profit = 0;
        for (int i = 1; i < prices.length; i++) {
            if (prices[i] > prices[i - 1]) {
                profit += prices[i] - prices[i - 1];
            }
        }
        return profit;
    }
}
```

## 第七部分：算法与工程时空优化指南（Java 视角）

### 7.1 空间优化核心技巧与选择指南

在算法手撕与高并发 Java 工程中，空间优化的核心目标是**在可接受的时间开销内降低堆内存与栈内存占用，规避 `OutOfMemoryError` 与 `StackOverflowError`**。

#### 一、 四大维度空间优化策略

1. **数据结构层压缩**：
   - **滚动数组 / 状态变量压缩**：动态规划中将二维 `int[n][m]` 压缩为一维 `int[m]` 或有限个滚动变量（详见 6.4 节）。
   - **位存储与位图（`BitSet` / RoaringBitmap）**：海量布尔状态去重或百亿级 ID 判存时，使用 `java.util.BitSet` 或 `long` 位掩码替代 `HashSet<Integer>`，内存占用可压缩 **32~64 倍**。
   - **稀疏结构与游程编码（RLE）**：高维稀疏矩阵使用 `Map<Long, Integer>`（行列坐标编码为单个 `long` 键：`(long) row << 32 | (col & 0xFFFFFFFFL)`）替代二维大数组。
2. **算法逻辑层复用**：
   - **原地算法（In-place）**：通过双指针交换、三次反转、快慢指针覆写、摩尔投票等直接复用输入数组，将额外空间压至 $O(1)$。
   - **显式栈迭代替代深递归**：当递归深度可能超过 $10^4$ 时，JVM 栈帧极易触发 `StackOverflowError`，应改用 `Deque<Node> stack = new ArrayDeque<>()` 在堆内存中模拟迭代。
3. **Java 语言与 JVM 特性优化**：
   - **基本类型替代包装类**：严禁在大规模数值计算中使用 `List<Integer>` 或 `Integer[]`（每个 `Integer` 对象头 + 对齐填充占用 16~24 字节，比 4 字节 `int` 膨胀 4~6 倍），应使用 `int[]` 或 `IntStream`。
   - **对象复用与池化**：高频路径复用 `StringBuilder`、使用线程池（`ThreadPoolExecutor`）与数据库连接池（`HikariCP`），避免短命大对象引发频繁 Young GC。
   - **防范内存泄漏（Memory Leak）**：
     - `ThreadLocal` 用完必须在 `finally` 中调用 `remove()`；
     - 长生命周期集合（如静态 `Map` 缓存）需设置淘汰策略（使用 `Caffeine` / `Guava Cache` 或 `WeakHashMap`）。
4. **海量数据与大文件处理**：
   - **流式分块读取**：使用 `Files.lines(path)` 或 `BufferedReader` 逐行流式处理 GB 级日志，严禁使用 `Files.readAllLines()` 一次性载入内存。
   - **零拷贝与内存映射文件（`MappedByteBuffer`）**：通过 `FileChannel.map()` 将超大文件映射至操作系统的内核页缓存（Page Cache），无需占用 JVM 堆内内存。

#### 二、 空间优化场景速查表

| 典型痛点场景 | 推荐 Java 空间优化方案 | 空间收益 |
| :--- | :--- | :--- |
| 二维 DP 内存超限 (MLE) | 滚动数组（0-1 背包逆序一维数组、LCS 单行 + `prev`） | $O(n \times m) \rightarrow O(m)$ 或 $O(1)$ |
| 亿级整数去重 / 签到状态统计 | `java.util.BitSet` 或 `RoaringBitmap` | 相比 `HashSet` 节省 95% 以上内存 |
| 深度优先搜索 (DFS) 栈溢出 | `ArrayDeque` 显式栈迭代 或 改用 BFS | 消除 JVM 线程栈溢出风险 |
| 数组去重 / 旋转 / 分区 | 双指针快慢覆写、三次反转、三路分区 | $O(n) \rightarrow O(1)$ 原地完成 |
| 超大文件（10GB+）读取解析 | `BufferedReader` 流式按行处理 或 `MappedByteBuffer` | 堆内存恒定 $O(1)$ |

### 7.2 时间优化核心技巧与选择指南

时间优化遵循 **“先降复杂度量级（宏观算法），再消冗余开销（微观实现），最后榨干硬件并发（系统底层）”** 的黄金法则。

#### 一、 三大层级时间优化策略

1. **算法层降维（根源提速）**：
   - **空间换时间预处理**：
     - 频繁单点查找：$O(n)$ 列表遍历 $\rightarrow$ $O(1)$ `HashMap` / `HashSet` 或定长数组哈希 `int[128]`；
     - 频繁区间求和：$O(n)$ 循环累加 $\rightarrow$ $O(1)$ **前缀和**；
     - 频繁区间加减：$O(n)$ 批量修改 $\rightarrow$ $O(1)$ **差分数组**。
   - **双指针与单调结构消除内层循环**：利用有序性（二分查找 $O(\log n)$、相向双指针 $O(n)$）或单调性（滑动窗口、单调栈、单调队列）将暴力 $O(n^2)$ 降为线性 $O(n)$。
   - **记忆化搜索与动态规划**：使用 `dp[]` 数组或 `memo` 缓存重叠子问题，将指数级 $O(2^n)$ 降为多项式级。
   - **回溯搜索剪枝（Pruning）**：提前排序 + 越界剪枝 + 同层去重（`if (i > start && nums[i] == nums[i-1]) continue;`），大幅砍掉无效搜索分支。
2. **Java 代码实现层消冗**：
   - **容器初始化指定容量**：已知数据规模 `n` 时，使用 `new ArrayList<>(n)` 或 `new HashMap<>((int) (n / 0.75f) + 1)`，彻底消除动态扩容与 `rehash` 拷贝开销。
   - **字符串拼接优化**：循环内拼接字符串严禁使用 `+`，统一使用 `StringBuilder`；正则表达式 `Pattern.compile()` 必须提取为 `static final` 常量。
   - **集合选型精准匹配**：栈与队列首选基于循环数组的 `ArrayDeque`（绝不用遗留同步类 `Stack`/`Vector`，且比 `LinkedList` 缓存命中率更高）。
3. **并发、I/O 与硬件底层加速**：
   - **批量与异步 I/O**：文件读写必套 `BufferedInputStream`/`BufferedWriter` 或使用 NIO `FileChannel`；网络远程调用使用 `CompletableFuture` 或 **JDK 21 虚拟线程** 并行化串行 RPC，将总耗时从 $\sum T_i$ 降至 $\max(T_i)$。
   - **降低锁竞争开销**：缩小同步代码块范围、读写分离（`ReentrantReadWriteLock` / `StampedLock`）、分段 CAS（`LongAdder` / `ConcurrentHashMap`）替代全局重量级锁。
   - **CPU 缓存友好性（Cache Locality）**：二维数组遍历严格遵循**行优先**（`matrix[i][j]` 外层 `i` 内层 `j`），顺应 CPU Cache Line 预取机制。

#### 二、 时间优化场景速查表

| 性能瓶颈特征 | 推荐优化手段 | 时间复杂度跃迁 |
| :--- | :--- | :--- |
| 嵌套循环查找配对 / 子数组和 | 哈希表（两数之和）、前缀和 + 哈希表、滑动窗口 | $O(n^2) \rightarrow O(n)$ |
| 频繁维护窗口极值 / 第 K 大 | 单调双端队列 (`ArrayDeque`) / 容量为 K 的小顶堆 (`PriorityQueue`) | $O(n \cdot k) \rightarrow O(n)$ 或 $O(n \log k)$ |
| 递归存在大量重复子问题 | 记忆化数组 `memo` 或自底向上动态规划 | $O(2^n) \rightarrow O(n)$ 或 $O(n^2)$ |
| 多步独立远程调用 / 阻塞 I/O | `CompletableFuture.allOf` 并行编排 / JDK 21 虚拟线程 | 串行累加耗时 $\rightarrow$ 最慢单任务耗时 |
| 高并发热点计数器锁竞争激烈 | `LongAdder` / `ConcurrentHashMap.computeIfAbsent` | 重量级锁阻塞 $\rightarrow$ 分段 CAS 无锁并发 |
