# Java研究生秋招20k｜Java源码面试分类整理
> 目标：20k薪资（后端开发，硕士秋招，大厂/中厂），面试高频源码，按模块分类，标注**面试考察重点**，很多题会追问底层原理、优缺点、并发问题。

## 一、集合框架源码（必问，占比最高）
### List
1. **ArrayList**
- 底层数组、默认容量、扩容机制、`grow()`、`ensureCapacity()`
- 为什么线程不安全；modCount、fail‑fast快速失败；remove、add元素拷贝
- 面试点：扩容是1.5倍；`toArray()`坑；subList不是新集合，是视图
2. **LinkedList**
- 双向链表，Node节点；add/get/remove时间复杂度；与ArrayList对比
- 可以做队列、栈；随机访问慢
3. **Vector**（考的少，对比ArrayList）
- 方法加synchronized，线程安全，扩容2倍，性能差

### Set
1. **HashSet**
- 底层基于HashMap，value是固定Object对象；add、remove直接调用map
2. **TreeSet**
- 底层TreeMap，红黑树；元素必须实现Comparable或传入Comparator；有序

### Map（重中之重，秋招高频）
1. **HashMap【最高频】**
- JDK1.7 vs JDK1.8重大改动：数组+链表 → 数组+链表+红黑树
- 核心参数：初始容量16，负载因子0.75，树化阈值8，退树阈值6
- put完整流程源码思路；hash扰动函数；resize扩容；链表头插改尾插（解决1.7循环链表死循环）
- get流程；remove；modCount；fail‑fast
- 面试追问：为什么负载因子0.75；为什么树化8、退树6；为什么容量必须2的幂
2. **ConcurrentHashMap【并发必问】**
- JDK1.7：分段锁Segment；JDK1.8：取消Segment，CAS+synchronized锁头节点
- put流程；size()统计；get不加锁；红黑树转换；扩容transfer；
- 为什么比HashTable性能好；与HashMap区别
3. **TreeMap**：红黑树实现，key有序

## 二、JUC并发包源码（20k必面，硕士秋招重点）
### 1. AQS AbstractQueuedSynchronizer（并发基石，经常深挖）
- AQS双向CLH队列；state状态变量；独占模式、共享模式
- `acquire()`、`release()`；`acquireShared()`、`releaseShared()`
- tryAcquire/tryRelease模板方法；Node节点；waitStatus状态；
- 中断：acquire不响应中断，acquireInterruptibly响应中断
> 面试：ReentrantLock、CountDownLatch底层都是AQS

### 2. 锁
1. **ReentrantLock**
- 可重入锁；公平锁FairSync / 非公平锁NonfairSync源码区别；
- lock()、unlock()；tryLock；可中断；支持条件变量Condition
2. **ReentrantReadWriteLock**读写锁
- state高低位拆分，高16读锁，低16写锁；写锁独占，读锁共享；
- 写锁可重入；读锁不能升级写锁；写锁可以降级读锁（高频面试点）

### 3. 工具类
1. **CountDownLatch**：共享AQS；countDown()、await()；不能重置
2. **CyclicBarrier**：可循环复用；栅栏；代Generation；await
3. **Semaphore**：信号量，共享AQS；控制许可，限流

### 4. 线程池 ThreadPoolExecutor【超级高频】
- 7大参数：核心线程数、最大线程、空闲存活时间、队列、线程工厂、拒绝策略
- execute()完整执行流程源码思路；addWorker()；worker内部类（实现Runnable）
- 4种拒绝策略；核心线程会不会超时；allowCoreThreadTimeOut
- submit()与execute区别；FutureTask源码；
- 面试：为什么不建议Executors快捷创建线程池；核心线程回收

### 5. 阻塞队列（并发集合）
- ArrayBlockingQueue：数组，一把锁；
- LinkedBlockingQueue：链表，两把锁读写分离；
- PriorityBlockingQueue；DelayQueue（定时任务底层）

### 6. CAS相关
- Unsafe类；compareAndSwapObject；自旋；ABA问题；AtomicXXX原子类
- AtomicInteger底层；LongAdder分段累加，高并发优化，对比AtomicLong

## 三、JVM & Object基础源码

2. **String、StringBuilder、StringBuffer**
- String底层：JDK9 char[] → byte[]；不可变原理；final修饰char数组

- StringBuilder非线程安全；StringBuffer方法synchronized线程安全
